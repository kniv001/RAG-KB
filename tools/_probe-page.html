限流方案选型速查

本文给出一份可直接照抄的选型对照，覆盖四种常见限流方案的适用场景与代价。

一、四种方案对照

方案突发流量实现复杂度典型场景
计数器不支持低内部接口兜底
滑动窗口不支持中对精度要求高的公开接口
漏桶不支持（强行平滑）低下游处理能力恒定
令牌桶支持低抢购、秒杀类突发流量

二、参数怎么定

令牌桶的两个参数是速率 r 与桶容量 b。突发量等于 b，平均速率等于 r。 例如 r = 2r/s、b = 3 时，桶最多攒 3 个令牌，瞬时最多放 3 个请求进来。

2.1 一个坑

桶容量不是越大越好：b 太大等于没有限流，b = 0 则退化成固定速率。

RateLimiter limiter = RateLimiter.create(2);
limiter.acquire();   // 立即返回
limiter.acquire();   // 需要等待约 500ms
